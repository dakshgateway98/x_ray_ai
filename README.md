# X-ray AI

Educational demo: upload a chest/body X-ray, run a vision model, then retrieve medical-book context (RAG) and store a structured write-up. **Not a medical device** — do not use it for diagnosis or patient care.

## Stack

React + TypeScript (Vite) · FastAPI · PostgreSQL · Redis · Celery · OpenAI / Gemini vision · ChromaDB

## Run

```bash
git clone https://github.com/dakshgateway98/x_ray_ai.git
cd x_ray_ai
cp env.example .env
# put at least one of OPENAI_API_KEY or GEMINI_API_KEY in .env
docker compose up --build
```

| Service | URL |
| --- | --- |
| UI | http://localhost:5173 |
| API + Swagger | http://localhost:8000/docs |

Frontend without Docker:

```bash
cd frontend
npm install
npm run dev
```

The Vite proxy forwards `/api` to `http://localhost:8000` (override with `VITE_API_URL`).

## What it does

1. Create a patient
2. Upload an X-ray (and optional clinical notes)
3. Celery worker runs vision analysis + optional literature retrieval
4. View the generated findings in the UI

Medical PDFs can be uploaded so retrieval has a local corpus.

## Layout

```text
api/          FastAPI routers
db/           SQLAlchemy models and schemas
services/     vision + LLM
tasks/        Celery jobs
frontend/     React app
```

## Disclaimer

Outputs are generated by third-party models and can be wrong. This repo is a software portfolio piece, not clinical software.
